## 确证问题与最小修复

| 问题 | 触发与根因 | 修复及验证 |
|---|---|---|
| 伪造网关身份 | 4 个 Servlet 身份过滤器在签名秘密为空时只告警，继续接受身份头 | 改为拒绝认证；补充 4 个回归断言。实际 7 个业务服务均拒绝伪造身份，返回 401；Gateway 剥离客户端伪造的身份头 |
| 空库标准启动失败 | 基础字典断言预期 125 行，正式种子的 17 类和 84 值实际为 101 行 | 将快照与正式种子对齐，不修改不可变种子；全新初始化与重放的 25 项断言通过 |
| 新增品类阻断重放 | 默认采购配置断言将用户新增品类计入固定快照 | 仅按 13 个正式品类自然键取快照；新增品类正例通过，缺少正式 PAPER 品类的负例仍失败，随后恢复 |
| Nacos 管理 API 未认证 | 正式配置没有启用服务端认证，匿名配置写入探针实际返回 200 | 启用认证；迁移器将公开引导 BCrypt 密码替换为私有秘密，8 个应用及 CLI 使用统一凭据。匿名写入返回 403，配置密码可登录，公开密码无法签发令牌，8 个应用注册成功；探针已删除 |
| XXL-JOB 公开引导密码 | 3.3.1 的登录读取数据库，原 Compose 登录参数不会替换公开种子密码 | 迁移器只替换仍匹配公开引导摘要的管理员密码，执行器同步私有凭据。配置密码登录成功，公开 `123456` 被拒绝；密码长度满足厂商 UI 上限 |

Nacos 与 XXL-JOB 引导器在重放时均为 `updated=0`，不会覆盖已配置账号。不增加生产认证后门，不修改业务状态机，不升级无关依赖。
