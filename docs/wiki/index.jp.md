## ディレクトリの役割

| ディレクトリ | 担当する内容 | 入るタイミング |
|---|---|---|
| `omni-backend/` | Spring Boot マイクロサービスと common モジュール | バックエンド実装、認証、テナント、ワークフロー、業務ドメインを見るとき |
| `omni-frontend/` | Vue シングルアプリ（サイト、ワークスペース、コンソール、ポータル） | 画面、ルーティング、権限、フロントエンドテストを見るとき |
| `scaffold/` | モジュールカタログと五つのプリセットの単一の事実源 | プリセットを選ぶ・絞り込む、モジュールの依存関係を確認するとき |
| `database/` | Liquibase マイグレーションとシードアサーションのマニフェスト | テーブル構造、シード、マイグレーション状態を確認するとき |
| `docker/` | アプリケーション、ツール、ドキュメントイメージのビルドファイル | イメージをビルドまたは配備するとき |
| `docs/` | 事実ドキュメント、ガイド、Wiki、ドキュメント品質スクリプト | 契約、チュートリアル、公開状態を調べるとき |
| `ai/` | 共有 AI 資産の規範ソースと派生 adapter | AI ワークフローを利用または保守するとき |
| `tools/` | CLI、プリセット生成、ドキュメントと品質のスクリプト | プリセットを生成する、品質ゲートやドキュメント検査を実行するとき |
| `observability/` | メトリクス、トレーシング、ログ、アラートの設定 | ローカルの可観測性スタックを設定するとき |
| `scripts/` | 正式な SQL シード、fixture、運用スクリプト | データを初期化する、統制された fixture を実行するとき |

この表は役割と入るタイミングだけを示します。具体的なクラス、インターフェース、データフローは対応する事実ドキュメントとソースを基準にしてください。

## リポジトリの関係

ソースコードは [Gitee](https://gitee.com/wang-baohai/Omni-Stack) を `origin`（fetch/push）とし、[GitHub](https://github.com/wang-baohai/Omni-Stack) を push 先のリモートとしています。Wiki の本文はこのリポジトリの `docs/` から生成され、マニフェストからサイトを生成するため本文の二重管理はありません。中国語が内容の基準であり、他言語のレビュー状態は[ドキュメントマニフェスト](../docs-manifest.yaml)に従います。サイトがビルドできることは、翻訳がレビュー済みであることを意味しません。
