# CRM 完全業務フロー

CRM は営業概要、リード、顧客、連絡先、商談、活動を扱います。テナント分離に所有者、組織データ範囲、レコードアクセスガードを重ねます。

## 1. 推奨フロー

```text
リード登録 → 重複確認と適格判定 → 顧客/連絡先/商談へ変換
→ 商談ステージ更新 → 活動記録 → 受注または失注
```

## 2. リード

リードを登録し、重複候補を確認して、ソースと担当者を設定します。適格リードは顧客、連絡先、任意の商談へ原子的に変換できます。変換は一度だけで、状態機械とトランザクションが重複生成を防ぎます。

## 3. 顧客と連絡先

顧客 360 は基本情報、連絡先、商談、活動を集約します。状態は潜在、活動中、休眠、流失、ブラックリストです。未完了商談がある顧客は削除を拒否できます。子リソースの可視性は顧客集約から継承します。

## 4. 商談

パイプライン、ステージ、金額、通貨、確度、予定日、担当者を管理します。表は精密検索、ボードは進行管理に使います。バックエンド状態機械が不正な遷移を拒否し、受注/失注後の再開は専用操作で履歴を保持します。

## 5. 活動

電話、会議、メール、訪問、メモを各集約に関連付けます。日時は `yyyy-MM-dd HH:mm:ss`。タイムラインは権限で絞り、参照不可の集約を漏らしません。

## 6. 概要

ファネル、顧客状態、商談金額、ステージ分布、最近の活動は実データを表示し、データがない場合は明確な空状態を表示します。

## 7. 権限受入

スーパー管理者、部門営業、本人のみのユーザーで、メニュー、操作、件数、詳細、組織外 ID の 403/404、変換、割当、ステージ、ブラックリスト、削除を検証します。
