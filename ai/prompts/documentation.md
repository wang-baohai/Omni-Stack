# 文档修改模板

核对当前源码、catalog、Compose、迁移和种子，再修改文档。README 负责项目入口；工程事实记录行为和不变量；Wiki 解释从前提到预期结果的操作；ADR 保存理由和后果；历史结论绑定当时版本。

同步中文、英文、日文和韩文的正文、导航、图注及含界面文字的图片。命令、路径、协议字段和权限码保持一致。新增或移动路径同步清单、生成器、图片引用和 CI。

真实界面、测试与源码证据在本机 Docker 采集，记录环境、源摘要、镜像、工具、时间与检查结果。历史截图不得直接声明为当前复现。

刷新摘要后保留真实人工待复核状态。自动翻译、交叉审校与操作 Auto-review 不能填写人工签核。内容检查和严格发布门分别报告。
